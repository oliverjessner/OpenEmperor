# Reverse-engineering notes

This directory records independently observed facts, their evidence and provenance, and explicit unknowns. It is separate from implementation code. Do not add original assets, proprietary source, or decompiled code here.

The user supplies legally obtained game files, initially from the GOG distribution; this repository does not decode the installer. See [file formats](file-formats.md), the [research log](research-log.md), and the [read-only map profile](map-format.md). Document observed bytes and unresolved semantics without embedding proprietary files or treating reference implementations as copyable source.
