Music effect. It does **not** establish the complete Original wandering policy,

selected, explicitly authored Rule23 adapter; it is not full Original parity.

and [implementation assessment](oe57-venue-house-service.md) keep those boundaries.

## Spawn and owner

**EXE_OBSERVED:** Theatre75 publishes vtable `0x7ad608`. Its actual update
`+0x20 → 0x48bfa0 → 0x48cde0` passes subtype36 to the shared spawn path
`+0x234 → 0x51cf90`. Effective staffing (`0x48b780`) is zero when every received
performer slot is zero; otherwise it uses ordinary staffing. The Original gate
is the OR of Music/Acrobat/Drama slots. The isolated Music-only adapter must not
relabel Actor36 universally as Music for every Original venue.

The unsigned-byte attempt counter compares strictly above the selected
`0x5ab330` threshold. At full staffing the threshold is3: the fourth eligible
callback is due. A due attempt resets before factory `0x4ea050`; failure is not
a spawned actor or delivery. The checked Original source slot allows one active,
matching subtype36 actor linked through source `WORD+0x2e`. Its actual owner is
Actor `WORD+0x62`, assigned from the source identity. Stale/wrong-subtype/wrong-owner
links do not establish a second valid owner.

Subtype dispatch `0x4c7580` reads the actual actor type. The concrete subtype36
table entry `0x84ed24` resolves to `0x4d5d00`, which resolves that owner through
the Building manager and invokes owner `+0x24`. Theatre75 binds
`0x48b7e0 → 0x51d0c0`. Thus this is a concrete actor/owner/callback chain, not
an inference from a sprite group or model name.

## Actual movement and House effect

**EXE_OBSERVED:** shared movement paths `0x4e6d80`/`0x4e7eb0` reach `0x4eacd0`
at actual movement boundaries. This resolves the same owner and invokes its
`+0x28 → 0x429df0 → 0x429e10`. The distributor considers real Building IDs around
the actor's actual cell and calls owner `+0x2c`. For Theatre75 that callback is
`0x48b7f0`, distinct from the school callback `0x48ad20`.

The target must have status1 or3, House type2–17, nonzero Access and strictly
positive signed occupants. There is no empty-Elite exception. The source71
special branch is separate; ordinary Theatre75 checks the actual owner's
current retained subtype34 Music through `+0x25c`. Only a nonzero current Music
slot assigns exactly96 to House own-info `+0x2c` (`0x48b910..0x48b928`). The
House requirement and timer routines independently identify that byte as Music
and decrement a positive byte toward zero.

This is an assignment, not an addition. A true callback result can occur
without a Music grant; callback success alone is therefore not a visit witness.
Construction, proximity to the source, dispatch and received venue stock alone
establish no House effect. A dispatch-time Music observation cannot authorize
a later visit after the venue's current Music has expired.

The Original distributor scans near a moving actor. A visited House is **not**
proved to be that actor's route endpoint. Rule23's cached route to one selected
House and physical source return are an explicit authored replacement for the
unresolved roaming choice, with the evidenced effect applied only at arrival.

## Return, retirement and source changes

**EXE_OBSERVED:** the shared state table includes initial waiting, source-road
entry, movement and a source-directed return. At its return terminal indication,
Theatre's subtype36 `+0x23c → 0x48b9b0` permits actor removal. This differs from
the School211→Performer34 one-way arrival/retirement path. The venue initializer
`0x48b980 → 0x51d0a0` assigns initial state6 and subtype36 countdown
`200 + RNG%50`, with RNG result bounded0..32767. The value200..249 is not proved
to mean seconds or World ticks and is not imported as such.

At each shared lifecycle entry, owner `+0x240 → 0x416b90` checks source status;
status other than1 removes the actor. That local predicate does not check
current staffing or received Music. The House callback likewise contains no
local staffing/pause/fire test. The complete mapping of Original user pause,
fire and other lifecycle actions to this status remains **UNKNOWN**.

**AUTHORED:** Rule23 gates new attempts on an idle owned channel, actual current
Music, full staff, operation, no source fire and prepared road access. It reuses
the existing full-staff counter step at the independently evidenced threshold3;
no partial-staff Theatre behavior is admitted. At actual House arrival it checks
current Music and additionally rechecks source operation, staffing and fire.
Those extra arrival checks are conservative authored policy, not observations
of the local Original callback. A real begun trip remains physical after source
changes, waits on a road cut and returns through the shared navigator before
its lifetime identity retires. No source change teleports it home.

## Persistence boundary and Gate B decision

The generic copy operation `0x4c8b10` preserves actor fields, but a clone is not
a proof of complete Original binary-save serialization. This remains **UNKNOWN**;
OpenEmperor JSON is an independent format and never an Original savegame.

The source evidence admits the narrow authored Rule23 integration: paid
School211→Performer34 delivery, current Venue32 input, one actual venue-owned actor,
physical movement, eligible occupied-House Music96 and a physical return.
Its clocks, target selection, IDs and strict schema39 provenance are authored.
Gate B does not admit a claim of Original roaming, complete original save or
entertainment parity. Gameplay, restore and graphical acceptance are separately
reported in the [assessment](oe57-venue-house-service.md).
