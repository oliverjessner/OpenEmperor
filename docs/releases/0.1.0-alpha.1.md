# OpenEmperor 0.1.0-alpha.1

## What this alpha is

This is the first externally testable OpenEmperor sandbox candidate for native macOS arm64. It is an independently written clean-room project and uses game files from the tester's own legally obtained Emperor installation. It is not a drop-in replacement or a complete recreation of Emperor.

## What you can do

- Choose a supported standalone map through the main menu.
- Run the OpenEmperor Industry-v5 sandbox with two clay sources, two pottery works, one warehouse, up to four households, and five couriers.
- Build and remove roads, pause or step the simulation, and observe live routing and rerouting.
- Save and load OpenEmperor worlds.
- Use a curated visual preview automatically when the selected original-data set exactly matches the currently validated fingerprints.

The built-in compatibility package contains OpenEmperor metadata only: relative archive names, physical SG3 record numbers, anchors, clip order, preview timing, road masks, and exact SHA-256 fingerprints. It contains no original assets or decoded pixels. OpenEmperor still reads every displayed original image from files supplied by the tester.

One locally validated GOG-derived asset set is recognized only when all six relevant SG3/.555 files match. Unknown revisions continue with subdued fallback roads, buildings, walkers, and unresolved-map diagnostics. Advanced users can select session-only custom walker, building, or road JSON overrides; clearing an override returns that category to automatic selection.

## Requirements

- Apple Silicon Mac; this candidate is built and tested for arm64.
- A legally obtained, installed or extracted copy of _Emperor: Rise of the Middle Kingdom_. Select the game data folder, not the GOG installer file.
- No original game data is included in OpenEmperor.

## Presentation and controls

Presentation mode is the default. It keeps diagnostic fallbacks visible with a muted palette and uses the curated original images when the exact compatibility package matches. Press F1 for the brighter research diagnostics and technical compatibility/source status; F1 changes no simulation or save state. The normal header exposes Help rather than Debug, and the HUD uses a larger text scale and a compact `Industry v5 | Tick … | Running …` status line.

Press H, ? or the visible Help action for the compact guide. Number keys 1–7 select tools, Space pauses, `.` steps, F5 saves, F9 loads, WASD or the arrow keys move the camera, the mouse wheel zooms, and Escape opens the menu. F2, F3, F4, F6, and F7 remain optional visual diagnostics.

## Known limitations

Original Emperor gameplay and saves are unsupported. Campaigns, trade, taxes, religion, military, monuments, much of the original rendering, elevation, and many map graphics are outside this alpha. Visual mappings are curated preview conventions, whole-image depth is approximate, horizontal mirroring is unverified, and four road-end masks use fallback tiles. Exact fingerprint recognition of one data set is not a claim of general or official GOG support. See [the full list](../../KNOWN_ISSUES.md).

The app is ad-hoc signed and not notarized. macOS may show a security warning. This release does not instruct users to disable Gatekeeper globally.

## Save compatibility

The candidate writes OpenEmperor schema-5 sandbox saves and has explicit migration paths for OpenEmperor schema 1–4. It does not read or write original Emperor savegames. Visual compatibility selection is session presentation state and is not stored in a save. Saves refer to the selected original map but contain no original image or map bytes.

## How to report a bug

Use the repository's bug-report form. Include the OpenEmperor version, macOS version, map, exact steps, expected result, actual result, visual-source status from F1, and any terminal error text. You may attach an OpenEmperor save when useful. Never upload original Emperor game files, the GOG installer, or proprietary assets.
