# OpenEmperor 0.1.0-alpha.1

## What this alpha is

This is the first externally testable OpenEmperor sandbox candidate for native macOS arm64. It is an independently written clean-room project and uses game files from the tester's own legally obtained Emperor installation. It is not a drop-in replacement or a complete recreation of Emperor.

## What you can do

- Choose a supported standalone map through the main menu.
- Run the OpenEmperor Industry-v5 sandbox with two clay sources, two pottery works, one warehouse, up to four households, and five couriers.
- Build and remove roads, pause or step the simulation, and observe live routing and rerouting.
- Save and load OpenEmperor worlds.
- Optionally use local curated JSON profiles to preview original walker, building, and road graphics supplied by you.

## Requirements

- Apple Silicon Mac; this candidate is built and tested for arm64.
- A legally obtained, installed or extracted copy of _Emperor: Rise of the Middle Kingdom_. Select the game data folder, not the GOG installer file.
- No original game data is included in OpenEmperor.

## Known limitations

Original Emperor gameplay and saves are unsupported. Campaigns, trade, taxes, religion, military, monuments, much of the original rendering, elevation, and many map graphics are outside this alpha. Visual mappings are curated diagnostics, whole-image depth is approximate, horizontal mirroring is unverified, and some road ends use diagnostic fallbacks. See [the full list](../../KNOWN_ISSUES.md).

The app is ad-hoc signed and not notarized. macOS may show a security warning. This release does not instruct users to disable Gatekeeper globally.

## Controls

Press H or ? in a sandbox for the complete compact guide. Number keys 1–7 select the available tools, Space pauses, `.` steps, F5 saves, F9 loads, WASD or the arrow keys move the camera, the mouse wheel zooms, and Escape opens the menu. F1 is debug information. F2, F3, F4, F6, and F7 are optional visual diagnostics.

## Save compatibility

The candidate writes OpenEmperor schema-5 sandbox saves and has explicit migration paths for OpenEmperor schema 1–4. It does not read or write original Emperor savegames. Saves refer to the selected original map but contain no original image or map bytes.

## How to report a bug

Use the repository's bug-report form. Include the OpenEmperor version, macOS version, map, exact steps, expected result, actual result, visual-profile status, and any terminal error text. You may attach an OpenEmperor save when useful. Never upload original Emperor game files, the GOG installer, or proprietary assets.
