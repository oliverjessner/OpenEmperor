# OpenEmperor 0.1.0-alpha.2 local candidate

This document describes a local test candidate. It does not replace or rewrite the historical alpha.1 notes, and it is not a published release.

## Candidate focus

- Fresh settings enter City-v11 rule 3 through a player-readable menu description.
- The recommended prepared settlement spends the ordinary 1,200 construction budget at tick 0, leaves 100 funds, and receives no goods, Service coverage, developed Houses, extra money, or hidden ticks.
- Markets distribute Food and Pottery. Complete Household supply can generate real tax income.
- Working buildings can be paused/resumed and assigned High, Normal, or Low workforce priority.
- New City-v11-v3 saves use schema 12. Existing v1/v2/schema-11 saves retain their rules unless the tester explicitly creates a v3 copy.

Display version `0.1.0-alpha.2`, City-v11 rule version `3`, and save schema `12` are separate version domains.

## Boundaries

This is an OpenEmperor-authored sandbox, not a complete Emperor reimplementation. Original saves and original simulation behavior are unsupported. Graphics are curated metadata mappings into files supplied by the tester, original-map rendering remains incomplete, and a city with exhausted population and goods may be unrecoverable.

The macOS bundle is ad-hoc signed and not notarized. A package built from a dirty workspace is a local candidate only. Publication still requires an owner-reviewed committed source state and a fresh package build. No original assets, personal saves, `.local/` content, screenshots, or private data paths may be distributed.
