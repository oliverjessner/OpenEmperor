- This alpha is an OpenEmperor sandbox, not Emperor gameplay parity.
- Original Emperor savegames are not supported. Only OpenEmperor sandbox saves are accepted.
- The automatic curated walker, building, and road preview is enabled only when all six core files in one locally validated GOG-derived asset set match exact SHA-256 fingerprints. Fire animation additionally checks its own two optional `destruction` dependencies; their failure does not disable compatible core previews. Other data revisions use named presentation fallbacks.
- The bundled compatibility profiles contain only OpenEmperor metadata. They do not contain original pixels or other original game bytes. Their visual mappings, anchors, timing, and road topology remain curated preview conventions.
- Advanced custom JSON profiles can override walker, building and road categories for one session. Invalid custom profiles fail explicitly; a damaged built-in profile falls back without blocking the sandbox.
- Presentation mode uses subdued diagnostic fallback colors. F1 exposes the brighter research diagnostics and technical visual-source status; this does not alter the World or save data.
- The independently reproduced repeated/fractional-zoom failure of SDL 3.4.14 software STATIC sprites is covered by a shared eager STREAMING compatibility policy and production pixel regressions. Native Metal and other runtime/backend combinations retain STATIC. This closes only the measured sprite-disappearance case; general rendering fidelity remains open. See [evidence, scope and acceptance boundary](docs/rendering/texture-compatibility.md).
- Whole-image depth sorting is approximate for overlapping original graphics. The bounded Great Wall early-base overwrite is addressed; interpenetrating sprites that require separate front/back components, original height normalization and restored historical-overlay eligibility remain open. See [scene composition](docs/rendering/scene-composition.md).
- Elevation and many original map graphics are incomplete.
- Horizontal mirroring is parsed but not applied because its behavior is unverified.
- Some original animation timing and pivot semantics remain unknown.
- For the studied byte-59 flagged Omega walkers, OpenEmperor presents exact `0x7c00` shadow markers as 50% black RGBA. This closely models the verified original RGB555 destination-halving branch, but 8-bit source-over rounding is not bit-identical to its 5-bit framebuffer result. The behavior is deliberately limited to that verified sprite profile; an original-game side-by-side capture is still unavailable.
