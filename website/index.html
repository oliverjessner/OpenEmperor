Raise the Middle Kingdom again.

OpenEmperor is an open-source, clean-room effort to bring Emperor: Rise of the Middle Kingdom to modern systems.

The first open-source recomp effort for Emperor. Built from research, reverse engineering and user-supplied original game data.
View on GitHub Try the alpha

Experimental software. Not affiliated with Activision, Sierra, Impressions Games or the original rights holders. Original game assets are not distributed.
